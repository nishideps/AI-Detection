# AI Detection

This provides the background code for a collaborative group project investigating whether stylometric methods can be used to build an AI Detector. We take a particular focus on ChatGPT evaluating the use of function words within essays generated based on a particular prompt and comparing it to human essays based on the same category. We build an algorithm using random forest sampling, multi-dimensional scaling and validate the statistical accuracy of the results obtained for a larger report.

This code is programmed in RStudio.
